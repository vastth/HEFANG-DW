# 业务数据推送数据库标准方案

## 业务数据推送数据库标准方案

由鸣民辜创建，最后修改于2024－09－03

## 一、业务背景

品牌提供MySQL数据库，数云将业务数据推送到品牌提供的数据库中。
推送到数据库的业务数据格式为json字符串，品牌IT需要自行解析。

## 二、业务数据
