# M1 只读审计报告：DWS 血缘与 ADS 依赖

---

## 1. 审计目标与边界

本轮目标是完成 M1 只读审计：梳理现有 `dws_sales_daily`、`dws_inventory_daily` 的源表、字段血缘、过滤条件、增量 / 快照策略、幂等策略，以及 ADS / 调度对 DWS 的真实依赖。

本轮边界：

1. 只读审计，不修改 ETL / SQL / 调度脚本。
2. 不执行数据库写操作，不执行 DDL、建索引、补数、回填或修数。
3. 只把审计结论落入子项目文档，作为 M2 设计冻结的输入。

## 3. 销售 DWS 审计

### 3.1 血缘与粒度

| 项 | 当前事实 | 证据 |
|----|----------|------|
| 目标表 | `dws_sales_daily` | `etl_dws_sales.py#L152-L160` |
| 源表 | `ods_m_retailitem` INNER JOIN `ods_m_retail`，LEFT JOIN `dim_store` | `etl_dws_sales.py#L56-L58` |
| 粒度 | `date_id + store_id + store_code + is_cloud_store + product_id + m_productalias_id` 聚合 | `etl_dws_sales.py#L44-L64` |
| 业务日期 | `r.billdate` | `etl_dws_sales.py#L44-L45` |
| SKU 字段 | `ri.m_productalias_id` | `etl_dws_sales.py#L48-L49` |
| 店仓属性 | `dim_store.store_code`、`dim_store.is_cloud_store` | `etl_dws_sales.py#L46-L47` |

### 3.2 过滤与口径

| 规则 | 当前事实 | 证据 |
|------|----------|------|
| 有效单据 | `r.isactive = 'Y'` | `etl_dws_sales.py#L59-L60` |
| 审核状态 | `r.status = 2` | `etl_dws_sales.py#L59-L61` |
| 日期窗口 | `r.billdate BETWEEN :start_date AND :end_date` | `etl_dws_sales.py#L61-L63` |
| SKU 非空 | `ri.m_productalias_id IS NOT NULL` | `etl_dws_sales.py#L64-L64` |
| 正单 / 退货 | 优先按单头 `tot_amt_actual` 正负判断，零金额用行级 `qty` 正负兜底 | `etl_dws_sales.py#L50-L55` |
| 订单数 | 只计正向销售单或零金额正数量单 | `etl_dws_sales.py#L55-L55` |

审计判断：这些规则适合作为 SKU 日销售汇总口径，但不应原样作为销售 DWD 的唯一事实范围。销售 DWD 候选应保留明细行、单头与行级字段，并把 `has_sku_flag`、`is_valid_for_sku_analysis` 等过滤标识显式派生，避免 DWD 层提前丢失无 SKU 明细。

### 3.3 增量与幂等性

| 项 | 当前事实 | 证据 |
|----|----------|------|
| 独立运行窗口 | 默认昨天；`include_today=True` 时按当前时段决定是否含今天 | `etl_dws_sales.py#L178-L210` |
| 主链窗口 | 当前主链使用 ODS 回刷窗口，即近 7 天并含今天 | `run_etl.py#L64-L65`、`run_etl.py#L651-L652` |
| 兜底回补 | 主链检查近 30 天 `COUNT(DISTINCT date_id)`，不足 30 天则触发 `backfill` | `run_etl.py#L654-L677` |
| 写入方式 | 同一事务内按日期范围 DELETE 后 INSERT | `etl_dws_sales.py#L139-L160` |
| 命名锁 | 使用 `hefang_dw:dws_sales_daily` | `etl_dws_sales.py#L134-L150` |

风险：当前命名锁未见显式 `RELEASE_LOCK`，主要依赖连接释放；后续若改造 DWS / DWD 长跑任务，应参考 `ads_inventory_health` 的显式释放模式。证据：`etl_dws_sales.py#L145-L175`、`etl_ads_health.py#L490-L504`。

## 4. 库存 DWS 审计

### 4.1 血缘与粒度

| 项 | 当前事实 | 证据 |
|----|----------|------|
| 目标表 | `dws_inventory_daily` | `etl_dws_inventory.py#L162-L168` |
| 源表 | `ods_fa_storage` LEFT JOIN `dim_store` | `etl_dws_inventory.py#L55-L56` |
| 快照日期 | 运行当天 `YYYYMMDD` | `etl_dws_inventory.py#L120-L127` |
| SKU 粒度 | `store_id + product_id + m_productalias_id`，重复组合在 transform 阶段合并 | `etl_dws_inventory.py#L105-L112` |
| 数量字段 | `qty` 与 `qty_valid` 均来自 `fs.qty`，`qtypurchaserem` 来自 `fs.qtypurchaserem` | `etl_dws_inventory.py#L52-L54` |
| 占用数量 | `qty_occupy` 固定为 0 | `etl_dws_inventory.py#L115-L115` |

### 4.2 过滤与口径

| 规则 | 当前事实 | 证据 |
|------|----------|------|
| 有效库存 | `fs.isactive = 'Y'` | `etl_dws_inventory.py#L57-L57` |
| SKU 非空 | `fs.m_productalias_id IS NOT NULL` | `etl_dws_inventory.py#L58-L58` |
| 店仓范围 | 只保留总仓 `001` 或云仓 | `etl_dws_inventory.py#L59-L59` |
| 品类范围 | 不做主销品类过滤，品类过滤在 ADS 层 | `docs/数据结构与映射手册.md#L532-L536` |

审计判断：当前库存 DWS 已提前限定总仓 / 云仓，适合作为库存健康主题的库存输入，但不适合作为全店仓库存 DWD。库存 DWD 候选应先保留更完整源侧事实，再由 DWS 输出总仓 / 云仓主题范围。

### 4.3 幂等性与超时风险

| 项 | 当前事实 | 证据 |
|----|----------|------|
| 写入方式 | 同一事务内删除当天快照后写入 | `etl_dws_inventory.py#L162-L168` |
| 命名锁 | 使用 `hefang_dw:dws_inventory_daily` | `etl_dws_inventory.py#L147-L161` |
| 命名锁释放 | 未见显式 `RELEASE_LOCK`，主要依赖连接释放 | `etl_dws_inventory.py#L156-L183` |
| 连接超时档 | `create_mysql_engine()` 未显式传 `timeout_profile`，默认落到 `default` | `etl_dws_inventory.py#L63-L64`、`etl_dws_inventory.py#L144-L145`、`db_connections.py#L85-L88` |

风险：库存 DWS 是每日全量快照，未来若扩展为全店仓 DWD 或历史快照回填，默认 60 秒读写超时不应作为最终方案。证据：`db_connections.py#L34-L60`。
