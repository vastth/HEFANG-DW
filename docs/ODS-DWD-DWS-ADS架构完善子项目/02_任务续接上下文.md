## 4. 已冻结的项目原则

1. 先创建文档骨架与路线，不直接改生产调度。
2. DWD / DWS 新开发必须先旁路运行，验证稳定后再考虑接入主链。
3. 任何写库、DDL、建索引、补数回填、修数操作由用户人工执行。
4. 每次实质推进必须更新本文件与推进看板。
5. 后续涉及数据库读写时，必须评估超时风险并记录 `timeout_profile` 选择与验证证据。
6. 新架构字段只取可用、真实有数据且语义明确的源字段；全量为 0 / 全量为空的 Oracle 模板化冗余字段不进入 raw ODS / DWD 草案 DDL。
7. 影子链替代旧链时，ADS 相关 MySQL 表的既有字段名属于外部消费契约；允许新增字段，但不得改名或删除既有字段，避免 Tableau 和其他下游报错。
