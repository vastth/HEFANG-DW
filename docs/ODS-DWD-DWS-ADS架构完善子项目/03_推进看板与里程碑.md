## 8. 更新规则

1. 每次完成任务后，在“当前任务看板”更新状态。
2. 每次进入新阶段后，更新“当前阶段”和“里程碑总览”。
3. 每次形成新证据后，在“推进日志”补充日期、事项、结果、后续。
4. 每次代码 / SQL / 调度有变更后，同步更新根文档和 `docs/AGENT_HANDOFF.md`。
