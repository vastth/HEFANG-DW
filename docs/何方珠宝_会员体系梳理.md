CREATE TABLE ads_member_rfm (

## ⚠️ 七、重要注意事项

### 7.1 字段名映射（易错点）

| 常见误用 | 正确字段名 | 所在表 |
|----------|------------|--------|
| ❌ CREATEDATE | ✅ **CREATIONDATE** | C_VIP |
| ❌ VIPNO | ✅ **CARDNO** | C_VIP |
| ❌ MOBILE | ✅ **MOBIL** | C_VIP |
| ❌ VIPTYPE | ✅ **NAME** | C_VIPTYPE |
| ❌ VIPDISCOUNT | ✅ **DISCOUNT** | C_VIPTYPE |
| ❌ TRADETIME | ✅ **BILLDATE** | M_RETAIL |

### 7.2 常用过滤条件

```sql
-- 有效会员
WHERE VIPSTATE = 'Y'

-- 有效订单
WHERE ISACTIVE = 'Y' AND STATUS = 2

-- 线下零售单
WHERE RETAILBILLTYPE = 'CMR'

-- 线上订单
WHERE RETAILBILLTYPE = 'EOR'

-- 近12个月数据
WHERE BILLDATE >= TO_NUMBER(TO_CHAR(ADD_MONTHS(SYSDATE, -12), 'YYYYMMDD'))
```

### 7.3 数据质量问题

| 问题 | 影响 | 建议 |
|------|------|------|
| 线上会员数据不完整 | O2O分析受限 | 补充天猫/京东/抖音会员ETL |
| 会员等级99%为珍珠/黄金 | 等级体系效果存疑 | 评估等级升级机制 |
| 会员关联率仅20% | 大量交易无法归因 | 推动门店会员绑定 |
