
# 敏感数据加密规则

## 一、背景描述

此加密规则，适用于标准化工具开发时，需要对字段进行加密或者解密时，提供的一种方案；

## 二、加密方式

加密算法：AES-128-ECB加密+BASE64加密

密钥类型：hex string （长度128 byte)

编码方式： UTF-8

加密方式：先对明文进行AES-128-ECB-PKCS5Padding加密, 再对结果进行BASE64加密

解密方式：先对密文做BASE64解密，然后进行AES-128-ECB-PKCS5Padding解密得到明文

from base64 import b64decode, b64encode
from Crypto.Cipher import AES
BLOCK_SIZE = AES.block_size
# 不足BLOCK_SIZE的补位(s可能是含中文，而中文字符utf-8编码占3个位置,gbk是2，所以需要以len(s.encode
pad = lambda s: s + (BLOCK_SIZE - len(s.encode()) % BLOCK_SIZE) * chr(BLOCK_SIZE - len(s.en
# 去除补位
unpad = lambda s: s[:-ord(s[len(s) - 1:])]
class AESCipher:
def __init__(self, secretkey: str):
self.key = bytes.fromhex(secretkey) # 密钥
self.iv = secretkey[0:16] # 偏移量
def encrypt(self, text):
"""
加密 ：先补位，再AES加密，后base64编码
:param text: 需加密的明文
:return:
"""
# text = pad(text) 包pycrypto的写法，加密函数可以接受str也可以接受bytess
text = pad(text).encode() # 包pycryptodome 的加密函数不接受str
cipher = AES.new(key=self.key, mode=AES.MODE_ECB)
encrypted_text = cipher.encrypt(text)
# 进行64位的编码,返回得到加密后的bytes，decode成字符串
return b64encode(encrypted_text).decode('utf-8')
def decrypt(self, encrypted_text):
"""
解密 ：偏移量为key[0:16]；先base64解，再AES解密，后取消补位
:param encrypted_text : 已经加密的密文
:return:
"""
encrypted_text = b64decode(encrypted_text)
cipher = AES.new(key=self.key, mode=AES.MODE_ECB)
decrypted_text = cipher.decrypt(encrypted_text)
return unpad(decrypted_text).decode('utf-8')
