# 伯俊建模三表数据字典

说明：
- 本文档覆盖 3 张 Tableau 直连 Oracle 逻辑表：销售订单事实表、商品维表、门店维表。
- 字段类型与字段样本来自 Oracle 只读执行结果，证据文件为 reports/context_cache/bojun_tableau_three_tables_profile.json。
- 字段样本取样规则：每张逻辑表扫描前 80 行，字段样本优先取首个非空值；若未命中非空值，则记为 NULL。
- 当前表名使用逻辑输出名，不等同于 Oracle 物理源表名。
